# Sample audio

This repository ships **no speech recordings**. The `generated/` folder (created by `npm run samples:audio`) contains synthetic sine-tone WAV files that exist only to exercise the evaluation pipeline end to end. They carry no rights issues because they contain no voice.

Real recordings must be collected under the consent process in `docs/07-native-speaker-validation-plan.md`, stored outside the public repository, and referenced from evaluation items by `audioPath` and `speaker.consentId`.
