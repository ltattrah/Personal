# Sample text data

All files here are original text written by the GhanaVoice engineering team and released under CC BY 4.0 for use in this project. Twi, Ewe and Ga sentences are **drafts pending native-speaker validation** and must not be treated as reference translations until reviewed (see docs/07).

- `questions.sample.jsonl`: example citizen questions per language, used for manual testing and as seeds for the retrieval evaluation set.
